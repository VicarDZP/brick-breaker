# 水果迷宫打砖块

一个免费开放的浏览器小游戏，也可以作为编程初学者阅读和练习的案例。

## 在线体验

https://vicardzp.github.io/brick-breaker/

## 本地运行

直接用浏览器打开 `index.html`，或在项目目录启动一个静态 HTTP 服务。

## 游戏操作

- ← / →：移动挡板
- 鼠标或触屏：移动挡板
- P：暂停 / 继续
- 空格或点击画布：开始游戏、进入下一关
- 点击「重新开始」：从第一关重新开始

## 项目文件

- `index.html`：游戏页面结构，以及 Java 初学者教学说明
- `style.css`：页面样式
- `game.js`：游戏逻辑，包括小球、砖块、碰撞、道具、计分和关卡

## 给 Java 初学者的说明

本项目的网页游戏使用 **HTML、CSS 和 JavaScript** 开发，并不是 Java 程序。Java 与 JavaScript 是不同的语言。

页面中的「编程入门」部分提供了一段可独立运行的 Java 控制台示例，演示变量、数组、for 循环和 if 条件判断。它用于帮助 Java 初学者理解游戏中的基本逻辑，不会被浏览器当作游戏代码执行。

建议学习顺序：

1. 阅读 Java 示例，理解变量、数组、循环和条件判断。
2. 查看 `game.js` 中的 `destroyBrick()`，理解击碎砖块和增加分数。
3. 查看 `createBricks()`，理解如何通过循环创建多个砖块。
4. 查看 `checkBrickCollision()`，尝试理解碰撞检测。
5. 修改砖块分数、关卡布局或小球速度，观察变化。
