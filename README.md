# 水果迷宫打砖块

一个基于 HTML、CSS 和原生 JavaScript 的浏览器小游戏。

## 在线体验

启用 GitHub Pages 并完成首次部署后，可通过以下地址访问：

https://vicardzp.github.io/brick-breaker/

## 本地运行

直接用浏览器打开 `index.html`，或在项目目录启动一个静态 HTTP 服务。

## 项目文件

- `index.html`：游戏页面结构
- `style.css`：页面样式
- `game.js`：游戏逻辑
