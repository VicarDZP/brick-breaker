从这个小游戏认识编程

如果你正在学习 Java，可以先从下面这段小程序认识游戏中常见的编程概念。

先分清 Java 和 JavaScript

这个网页小游戏是用 HTML、CSS 和 JavaScript 编写的，浏览器运行的是 JavaScript。Java 和 JavaScript 是两种不同的编程语言。下面的代码是专门给 Java 初学者看的控制台入门示例，用来理解游戏中的得分和砖块逻辑，并不是网页游戏本身的源代码。

1. Java 入门示例：击碎砖块并计算分数

这段代码模拟击碎 5 块砖块：每击碎一块加 10 分，最后输出总分。可以复制到 Java IDE 中，保存为 BeginnerGame.java 后运行。

public class BeginnerGame {

    public static void main(String[] args) {
        // 变量：记录当前分数
        int score = 0;

        // 数组：1 表示砖块还在，0 表示已经击碎
        int[] bricks = {1, 1, 1, 1, 1};

        // 循环：依次检查每一块砖
        for (int i = 0; i < bricks.length; i++) {

            // 判断：如果砖块还存在
            if (bricks[i] == 1) {
                score = score + 10;
                bricks[i] = 0;
                System.out.println("击碎第 " + (i + 1) + " 块砖！");
            }
        }

        // 输出最终结果
        System.out.println("游戏得分：" + score);
    }
}

2. 这段代码用到了哪些 Java 知识？

变量

int score = 0;

用变量保存会变化的数据，例如分数、生命值和当前关卡。

数组

int[] bricks

用一组数据表示多块砖。数组下标从 0 开始。

循环

for (...)

重复执行相同操作，例如逐个检查所有砖块。

条件判断

if (...)

根据条件决定是否执行，例如只给尚未击碎的砖块加分。

3. 再看看真实游戏代码在哪里

  • index.html：网页结构，放置游戏画布和按钮。
  • style.css：控制页面颜色、布局和按钮样式。
  • game.js：真正的游戏逻辑，包括小球移动、碰撞检测、计分和关卡切换。
